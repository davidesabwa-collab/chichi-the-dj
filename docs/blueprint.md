# **App Name**: Chichi The DJ Official

## Core Features:

- Homepage Hero: Displays a hero section with a full-screen background image of Chichi The DJ, logo/name, a CTA button, and a short tagline.
- About Section: Showcase the DJ's background and philosophy in an About section.
- Bookings & Contact: Provide a comprehensive services section with a contact form to facilitate booking inquiries.
- Music Player: Allow the user to listen to curated music mixes via embedded SoundCloud or Mixcloud sets.
- Events Display: Highlight past performances with bold dates, event posters, and a call to action for promoters.
- Gallery Section: Curate an engaging photo gallery of behind-the-scenes and crowd images with hover effects.
- Socials and Contact Footer: Consolidate all contact info, socials in a neat easily accessible area.

## Style Guidelines:

- Primary color: Electric Pink (#F043D5) for a vibrant, nightlife feel.
- Background color: Near-black (#08070A) provides a modern, high-contrast stage.
- Accent color: Cyan (#4FF0FF) highlights key elements for engagement.
- Font: 'Space Grotesk' (sans-serif) for a modern and bold look. Use for headlines and short blocks of text.
- Use bold and neon-colored icons for social media and contact information.
- Employ a full-screen, responsive design for an immersive user experience.
- Incorporate subtle animations for scrolling and hover effects to enhance interactivity.
